# ⏰ ふわふわタイマー / ARK Breeding Timer

**かわいい見た目の Windows デスクトップタイマー。**
ふつうのタイマーとしても、ARK: Survival Ascended のブリーディング用としても使えます。
ゲームの横に置いておける**ミニ表示**と、やることを書き留めておける**チェックリスト**つき。

Python 標準ライブラリだけで動きます（追加パッケージなし）。

## できること

### ⏰ 自由タイマー
- **◯時間◯分◯秒後**（1分 / 3分 / 5分 / 10分 / 15分 / 30分 / 1時間 / 3時間 のワンタッチつき）
- **指定した時刻に**（`21:30` / `21:30:00` / `8/5 21:30` / `25:00`＝翌1時）
  時刻だけ書いて既に過ぎていたら自動で「明日」になります
- 🔁 **くり返し** — **ずっと / ◯回まで** を選べて、**2回目からの間隔**も別に決められます
  （例: 最初は5分後、そのあとは15分ごとに3回）。作ったあとでもカードの **🔁** から変えられます
- タイマーごとに**鳴らす音を変えられます**
- メインの画面からワンクリックで作れる「さくっと」ボタン（**名前も長さも自由に変えられます**）

### 🦖 ARK ブリーディング
恐竜を選ぶだけで、サーバー倍率から実時間を計算してタイマーを作ります。

| 種類 | 内容 |
|---|---|
| 🥚 孵化 | 卵が孵るまで。終わると成長・刷り込みタイマーを**自動で作成** |
| 🌸 妊娠 | 胎生（パイロメイン・オヴィスなど）の出産まで |
| 🌱 成長 | 成体まで。**10%（放置できるようになる時点）** でも通知 |
| 💗 刷り込み | 間隔ごとに繰り返し通知。「✔ できた」で次の回へ。何回目 / 1回あたり何% / 累計% を表示 |
| 💞 再交配CD | 次に交配できるまで（最短〜最長） |

恐竜データは **315種**（ARK: Survival Ascended の公式値）。「レックス」「ギガ」のように日本語でも、`rex` `wyv` のように英語でも探せます。

#### 途中の個体も登録できます

| 始めかた | 使いどころ |
|---|---|
| **今から** | 産みたて・生まれたて |
| **成熟度 ◯% から** | **ゲーム内の「成熟度」の数字を入れるだけ**。既定は 0% |
| **残り時間 から** | ゲーム内に出ている残り時間をそのまま入れる |

成熟度を入れると、その場で「→ 成体まで あと 43:31 ／ 刷り込みは 2/5回目まで済み・次まで 9:23」
のように計算結果が出ます。**刷り込みの済んだ回数も自動で合わせる**ので、途中から拾った個体でも
「あと何回であと何%」がそのまま追えます。0% より大きいときは、もう生まれているので
孵化・妊娠のタイマーは作りません。

### 🍖 テイム
新しいタイマーの3つ目のタブです。**恐竜とレベルを選ぶだけ**でテイムにかかる時間を計算し、
そのままカウントダウンにできます。

- **必要な餌の数** と **かかる時間**
- **テイム効率（TE）** と **ボーナスLv**（テイム後のレベル）
- **気絶値**の最大値・減る速さ・**起きるまでの時間**・必要な麻酔薬の数
- 餌は**その恐竜が食べるものだけ**が候補に出ます（生肉・キブル・マトンなど）
- **オプション: いまの食料値**を入れると、それを消費しきるまでの待ち時間も足して計算します
- `⚙ 設定 → 🦖 ARK倍率` に**テイム速度・食料の減り・気絶値の減り**の倍率があります

<img src="docs/taming.png" width="640">

計算は [ARKStatsExtractor](https://github.com/cadon/ARKStatsExtractor) の `Taming.cs` を
そのまま移したものです。1倍設定で Rex Lv150 = 生肉130個・4時間20分・TE 55.2%・+41Lv、
エクセプショナルキブル17個・TE 98.7%・+74Lv となり、よく知られた値と一致します。

> **データの限界について。**
> テイム餌のデータ（`tamingFoodData.json`）は ARKStatsExtractor が手で保守しているもので、
> ASAのアイテム（強化キブル）は入っている一方、**ASAで追加された恐竜そのものはまだ未収録**です。
> 上流の最新版でもそうなので、こちらで直せるものではありません。そのため:
>
> - **直接データがある: 159種**
> - **変種として元の種族から借りている: 54種**（`X-スピノ` → `スピノ` など。食性は同じです）
> - **不明: 残り**（カルカロ、ケラトサウルス、アンドリューサルクスなど）。
>   この場合は一般的な食料値で概算し、画面に ⚠ を出します。数値は目安として見てください
> - **テイム効率（TE）や気絶値**のデータが無い恐竜もいます（Rexは気絶値が不明など）。
>   その項目は「データ無し」と表示します

<img src="docs/new-timer.png" width="640">

### 🔔 音・通知
- **内蔵音7種**（ちりん / ぽろん / きらきら / ぴこぴこ / ぽん / アラーム / ピピピ）
  ― 音源ファイルは同梱せず、起動時に**自前で合成**しています
- **自分の mp3 / wav / m4a** も選べます
- **音量スライダー**（内蔵音は波形に音量を焼き込み、mp3等は MCI 経由で音量指定）
- 画面のすみにポップアップ（**ゲームからフォーカスは奪いません**）
- ポップアップは**放っておくと自分で消えます**。残り時間が細いバーで出ます
  （既定: 予告は8秒で消える／鳴ったときは「とめる」を押すまで残る。どちらも秒数で変えられます）
- Windows のトースト通知 / タスクバー点滅
- **◯秒前の予告通知**（既定 60秒、変更・オフ可）
- 「とめる」を押すまで音をくり返す

<img src="docs/settings.png" width="480">

### ⏰ タイマーの設定
`⚙ 設定 → ⏰ タイマー` で、使い勝手まわりを変えられます。

- **さくっとボタン**の中身（名前と長さ）。追加・削除・「はじめの並びに戻す」つき。
  ここで決めたものがメイン画面とミニ表示の両方に出ます（ミニ表示は先頭4つ）
- **終わったタイマーの片づけかた**を2つから選べます
  - **◯分たったら自動で消す**（既定・10分）。カードに「あと 9:58 で消えます」と出ます
  - **「✔ できた」を押したときだけ消す**（自動では消しません）

  どちらを選んでも、終わったタイマーには **「✔ できた」ボタン**が出て、押せばその場で片づきます。
  次のものは自動では消えません:
  - 刷り込みの「✔ できた」待ち（押すまで残ります）
  - くり返し中のもの／一時停止中のもの
  - 起動前に終わっていた分は、**起動してからこの時間だけ**残ります（開いた瞬間に消えたりしません）
- **✕ を押したときに確認するかどうか**。オフにすると押した瞬間に消えます

<img src="docs/settings-timer.png" width="480">

### 🗕 ミニ表示
ゲームの横に置いておく用の小さい窓です。ヘッダーの「🗕 ミニ表示」で開くと、
本体はしまわれてこれだけが残ります。**これだけで一通りの操作ができます。**

- **⏰ / 🗒 のタブ**で、タイマーとチェックリストを切り替えられます
- タイマーは**残り時間の短い順**に並び、終わったものは下に落ちます
- **「＋ 追加」で新しいタイマー**（本体と同じ画面が開きます）。5分 / 15分 / 1時間のワンタッチつき
- 各行の **×** で削除（確認が出ます）
- チェックリストは**本体と同じ中身**です。どちらで変えても両方に反映されます

タイマー1本ごとに、その場でこの3つを変えられます。

| | 内容 |
|---|---|
| **🔊** | このタイマーの音を鳴らすか |
| **🖥** | 終わったときメインモニターの**まんなかに大きく**出すか（ふだんは右上に小さく） |
| **🔁** | くり返しの設定（入切・回数・間隔） |
| スライダー | **このタイマーだけの音量**（未設定なら全体設定に従います） |

<img src="docs/mini.png" width="330">

窓の大きさ・位置・最後に開いていたタブは次回も覚えています。「戻る」で本体に戻ります。

### 🖱 マクロ（連射）
レベルアップの振り分けみたいに「同じ場所を何十回も押す」作業のためのものです。

- **左 / 右 / 中クリック**、または**任意のキー**を連打します
- キーは「キー: ◯◯」ボタンを押してから**使いたいキーを押すだけ**で決まります
- **間隔をミリ秒で指定**（50 / 100 / 200 / 500 / 1000 のワンタッチつき）。
  押している時間も別に指定できます
- **◯回で自動的に止める**（0 でずっと）
- **対象のアプリが最前面のときだけ動きます**（既定オン、AFK防止と同じしくみ）。
  デスクトップやエクスプローラーを触っている間に連打されないための安全装置です。
  裏に回っている間は撃たずに待機し、前に戻すと再開します。
  いまの状態は exe名の右に出ます:
  **✅ いま最前面です** / **⏸ 起動中（前に出れば動きます）** / **⚠ 見つかりません**
- **Ctrl+R でどこからでも入切**できます。ゲームの画面から手を離さずに止められます
- 「▶ 1回ためす」で1回だけ送って動きを確認できます
- **起動時は必ず停止状態**から始まります

<img src="docs/macro.png" width="640">

> **ショートカットについて**: `Ctrl+R` を登録している間は、**ブラウザなど他のアプリでも
> `Ctrl+R` が効かなくなります**（Windowsがこのアプリに横取りするため）。
> 気になるときは「Ctrl+R ▸ 変える」で別の組み合わせにするか、「使う」のチェックを外してください。

### 🌙 ゲーム内時計（マップごと）
ドレッドメアのように「夜しか出ない」相手を待つためのものです。

ARK には時刻を返すコマンドが無いので、**ゲーム内で H キーを押すと出る時刻を1回入れる**と、
あとは実時間から計算して進みます。他人のサーバーでも使えます。

- **マップごとに別々の時計**を持てます。名前を入れて「＋ 追加」するだけ
- 一覧でぜんぶのマップの「いまの時刻」「夜/朝まであと何分」が並びます
- **昼（05:30-17:30）と夜（17:30-05:30）の長さを分で指定**できます。サーバーごとに違うので
- **1分以上あけて2回目を合わせると、進む速さを自動で測り直します**
- 「🌙 夜を知らせる」「☀ 朝を知らせる」でタイマーになります
- **好きなゲーム内時刻**も指定できます（「ゲーム内 20:00 になったら ⏰知らせる」）
- ズレたら、いつでも入れ直して合わせ直せます

#### 定期再起動を登録しておくとズレが自動で直ります
ゲーム内時間は**サーバーが動いている間しか進みません**。定期再起動で落ちていた分だけ、
こちらの時計は進みすぎてズレます。

そこで「**毎日 6:00, 18:00 に、3分ほど止まる**」のように登録しておくと、
その時刻を過ぎたときに自動でその分を差し引きます。通信も監視も要らないので確実です。
アプリを閉じていた間に過ぎた再起動も、次に開いたときにまとめて反映します。

#### サーバーを見張る（A2Sが通るサーバーのみ）
ゲーム内時間は**サーバーが動いている間しか進みません**。定期再起動やクラッシュで
落ちていた分だけ、こちらの時計は進みすぎてズレます。

そこで、クエリポート（例 `1.2.3.4:27015`）を入れておくと **A2S** で定期的に生死を見に行き、
**落ちている間は時計を止めます**。再起動をまたいでも合ったままになります。
「▶ ためす」でその場につながるか確認できます（サーバー名・マップ・人数が返ります）。

<img src="docs/gametime.png" width="700">

### 🗒 チェックリスト
上の「🗒 チェックリスト」タブに切り替えると使えます。ステータスの測定手順や
やることのメモなど、タイマーと並べて置いておきたいものを書いておけます。

- **✓ 完了 / △ 保留 / ✗ 中止** の3状態
- **印を押すと「やること」から外れて**、それぞれのタブに移ります。
  もう一度同じ印を押せば戻ります。全部まとめて見たいときは「すべて」
- 絞り込みタブにはそれぞれ**件数**が出ます
- 項目を**ダブルクリックで書きかえ**、行の右端の × で削除
- 書いた内容は自動で保存され、閉じても消えません

<img src="docs/checklist.png" width="640">

### 🎮 AFK防止
放置していると蹴られるサーバー向けに、決めた間隔でキーを送ります。

- **送るキー**を選べます（スペース／W／A／S／D／←／→／Shift／Ctrl／Tab／1）。
  その場でジャンプするだけの**スペースが無難**です
- **何秒ごと**・**1回に何連打**・**連打の間隔**を指定できます
- 対象の exe 名は「いま最前面のを使う」ボタンで自動的に入ります
- 「▶ ためす」で**いま選んでいる送りかたで1回だけ送って**、効くかどうか確かめられます
- **起動時は必ず停止状態**から始まります

#### 送りかたは4つから選べます

| | 裏でも送れる？ | 中身と注意 |
|---|---|---|
| **ARKが最前面のときだけ**（既定） | ✗ | いちばん確実で安全。ARKを見ていない間は送られません |
| **一瞬だけ前に出して戻す** | ✓ | ARKを一瞬アクティブにして送り、すぐ元の窓に戻します。**たいてい効きます**が、そのとき画面が一瞬ちらつきます |
| **ウィンドウに直接送る** | ✓ | `WM_KEYDOWN` をウィンドウへ投げます。ちらつかず裏のままですが、**生入力しか見ないゲームには効きません**。まず「▶ ためす」で確認を |
| **前面が何でも送る** | — | ⚠ メモ帳やブラウザにも文字が入ります |

裏で動かしたいなら **「一瞬だけ前に出して戻す」がおすすめ**です。
「ウィンドウに直接送る」がARKで効けばそれが一番きれいなので、先に試してみてください。

<img src="docs/afk.png" width="640">

> 自分で建てているサーバーなら、`GameUserSettings.ini` の放置キック設定を切るほうが根本的です。

### ⬆ 更新
ヘッダーの「⬆ 更新」から、GitHubの最新版をその場で確認できます。

- 新しい版があれば **更新内容（リリースノート）をそのまま表示**します
- 「いますぐ更新」でダウンロード → 入れ替え → 起動し直しまで自動
- 「キャンセル」でやめられます。**勝手には更新しません**（自動チェックもしません）
- 設定・タイマー・チェックリストは `%APPDATA%` にあるので、**そのまま引き継がれます**
- ソースから動かしているときは「git pull してください」と出ます

### そのほか
- ⏰ タイマー / 🗒 チェックリスト / 🎮 AFK防止 / 🖱 マクロ / 🌙 ゲーム内時計 のタブ切り替え（最後に開いていたものを覚えます）
- ウィンドウを小さくするとボタン類が折り返され、狭いときはヘッダーが2段になります
- **エラーは別窓を出さず、その場に赤字で出ます**（×を押す手間がありません）。
  チェックリストの項目名も、ダブルクリックでその行のまま書きかえられます
- 終わったタイマーの **「✔ できた」** でその場で片づけ（ミニ表示の ✔ でも同じ）
- 一時停止、±5分の微調整、常に最前面
- タイトルバーに次のタイマーの残り時間（タスクバーで確認できます）
- **アプリを閉じても残り時間は消えません**（絶対時刻で保存）。起動前に終わっていたタイマーもまとめて知らせます

## つかいかた

### exe（Python不要）
[Releases](../../releases) から好きなものをどうぞ。

| | 中身 | むいている人 |
|---|---|---|
| `ArkBreedingTimer-x.y.z-setup.exe` | **インストーラ** | ふつうに入れたい人。**上書き更新できます** |
| `ArkBreedingTimer-x.y.z-win64.zip` | フォルダ一式 | インストールせず使いたい人。**ウイルス対策ソフトに消される場合もこちら** |
| `ArkBreedingTimer.exe` | 1ファイル | とりあえず動かしたい |

#### インストーラについて
- **管理者権限は要りません**（`%LOCALAPPDATA%\Programs\ArkBreedingTimer` に入ります）。
  UACの確認も出ません
- **すでに入っていれば、そのまま上書き更新**になります。
  アプリが動いていたら閉じてから入れ替えるので、起動したままでも大丈夫です
- スタートメニューのショートカット、デスクトップのショートカット（任意）、
  Windows起動時に自動で開く（任意）を選べます
- アンインストールは「設定 → アプリ」から。そのとき
  **設定・タイマー・チェックリストを消すかどうか聞きます**（「いいえ」なら残るので、
  入れ直したときに続きから使えます）

zip版は展開して中の `ArkBreedingTimer.exe` を実行してください。フォルダごと好きな場所に置けます。

### ⚠ ウイルス対策ソフトに引っかかったときは

Windows Defender が `Trojan:Win32/Wacatac.*!ml` などと言ってくることがあります。
これは**誤検知**です。末尾の `!ml` は「機械学習がなんとなく怪しいと判断した」という意味で、
特定のウイルスが見つかったわけではありません。

原因は中身ではなく作り方のほうで、

- PyInstaller の1ファイル形式は、起動時に自分を `%TEMP%` に展開して実行する
  → マルウェアの自己展開と見分けがつかない
- 有料の署名（コードサイニング証明書）を付けていない
- ダウンロード数が少なく「実績」が無い

の3つが重なると引っかかります。Python製のフリーソフトでは定番の症状です。

こちら側の対策として、ビルドでは次をやっています（`tools/build.py`）。

- **UPX圧縮を使わない**（圧縮exeは問答無用で疑われます）
- **バージョン情報を埋め込む**（作者・製品名・著作権が空だと疑われます）
- **フォルダ形式(zip)も配布する**（自己展開しないので、かなり通りやすくなります）

それでも消される場合は:

**Windows 11 の「スマート アプリ コントロール」がオンだと、署名の無いソフトはそもそも
起動をブロックされることがあります**（Defenderより強い仕組みです）。
`設定 → プライバシーとセキュリティ → Windows セキュリティ → アプリとブラウザーの制御`
で状態を確認できます。

それでも消される・動かない場合は:

1. **zip版を使う** — いちばん手軽です
2. **除外に追加する** — Windowsセキュリティ →「ウイルスと脅威の防止」→「設定の管理」
   →「除外」→ 置いたフォルダを追加
3. **誤検知として報告する** — [Microsoft Security Intelligence](https://www.microsoft.com/en-us/wdsi/filesubmission)
   に exe を出して「Incorrectly detected as malware」を選ぶと、たいてい数日で直り、
   ほかの人のところでも出なくなります

自分でソースからビルドすることもできます（下の「ファイル構成」参照）。

### ソースから
Python 3.10 以降（tkinter 同梱の通常のインストールでOK）。

```bat
python ark_breeding_timer.py
```

Windows なら同梱の `起動.bat` でコンソールなしで起動できます。

## ARK のサーバー倍率

`⚙ 設定 → 🦖 ARK倍率` に、サーバーの値を入れてください。

| 項目 | 既定値 |
|---|---|
| EggHatchSpeedMultiplier | 15 |
| BabyMatureSpeedMultiplier | 185 |
| BabyCuddleIntervalMultiplier | 0.03125 |
| MatingIntervalMultiplier | 0.001 |
| BabyImprintAmountMultiplier | 1 |

計算式:

```
孵化      = incubationTime / EggHatchSpeedMultiplier
妊娠      = gestationTime  / EggHatchSpeedMultiplier   （設定でオフにできます）
成長      = maturationTime / BabyMatureSpeedMultiplier
刷り込み間隔 = 8時間 × BabyCuddleIntervalMultiplier
刷り込み回数 = 成長時間 ÷ 刷り込み間隔（切り捨て、最低1回）
1回の刷り込み% = 刷り込み間隔 ÷ 成長時間 × 100 × BabyImprintAmountMultiplier
再交配CD  = matingCooldownMin〜Max × MatingIntervalMultiplier
```

上の既定値での例:

| 恐竜 | 孵化 / 妊娠 | 成長 | 刷り込み |
|---|---|---|---|
| Rex | 20:00 | 30:02 | 15分 × 2回（+50%） |
| Giganotosaurus | 3:19:59 | 1:19:08 | 15分 × 5回（+19%、ぜんぶで95%） |
| Pyromane | 妊娠 9:35 | 15:48 | 15分 × 1回 |
| Dodo | 3:20 | 5:00 | 15分 × 1回 |

> **妊娠時間について**: 妊娠に `EggHatchSpeedMultiplier` を掛けるかどうかは設定で切り替えられます。
> 実測とズレる場合はチェックを外すか、「残り時間から」でゲーム内の表示を入れて作ってください。

## ファイル構成

```
ark_breeding_timer.py    アプリ本体（ロジックと画面）
theme.py                 かわいい系UIキット（角丸カード・ボタン・スライダー）
sounds.py                音の合成と再生
afk.py                   AFK防止のキー送信（SendInput）
afk_page.py              AFK防止の画面
gametime.py              ゲーム内時計の計算（マップごと）
gametime_page.py         ゲーム内時計の画面
serverwatch.py           サーバーの死活監視（A2S）
macro.py                 マクロの連射スレッドとグローバルホットキー
macro_page.py            マクロの画面
taming.py                テイムの計算
updater.py               更新の確認と入れ替え
data/species.json        恐竜の交配データ 315種
data/taming.json         テイムのデータ 444種
tools/build.py           exeのビルド（誤検知対策こみ）
tools/build_species_db.py  恐竜データの生成
tools/build_taming_db.py   テイムデータの生成
tools/make_ico.py        アイコン(.ico)の生成
```

exe を自分でビルドするには（PyInstaller が要ります）:

```bat
pip install pyinstaller
python tools\build.py
```

`dist\` に1ファイル版とフォルダ版(zip)の両方ができて、最後に Defender で
スキャンした結果が出ます。`onefile` / `onedir` を引数に付けると片方だけ作れます。

設定・実行中タイマー・チェックリストの保存先: `%APPDATA%\ArkBreedingTimer\`
（`config.json` / `timers.json` / `checklist.json`）

恐竜データを最新にするには、[ARKStatsExtractor](https://github.com/cadon/ARKStatsExtractor) の
`values.json` と `ASA-values.json` を用意してから:

```bat
python tools\build_species_db.py <values.jsonのパス> <ASA-values.jsonのパス>
```
